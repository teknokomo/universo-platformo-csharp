# Project Brief

- Goal: Keep the Universo Platform landing experiences visually identical across stacks (Blazor WebAssembly with MudBlazor and the React/MUI backup).
- Scope: Guest start page with hero, product cards, and footer; includes top header with login entry and language toggle.
- Quality bar: Pixel-level parity with the React backup; reliable static assets; consistent i18n text in RU/EN.
- Data platform goal: maintain a stable EF Core 9 migration system that can target multiple databases while runtime data access remains browser-safe.
