# Product Context

- Purpose: Present the Universo ecosystem to unauthenticated visitors with a focused landing page and clear call-to-action.
- Ecosystem highlights: Kompendio, Platformo, Kiberplano, Grandaringo, plus contact/legal links for trust.
- UX goals: Full-bleed hero over a background image, central CTA to auth, product highlight cards, and a concise contact footer; layouts must look identical between Blazor and the React backup.
- Platform operations goal: keep schema evolution manageable across multiple database engines using one EF Core 9 migration workflow.
